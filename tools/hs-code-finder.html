How HS codes are built

The first six digits are harmonised across more than 200 economies. Beyond that, each country adds its own digits for duty rates and statistics — which is why a US HTS code and an EU CN code for the same item can differ after the sixth digit.

A five-step classification method

  1. Describe the product precisely: what it is, what it is made of, what it does, and how it is presented.
  2. Find the likely chapter here, then read that chapter's section and chapter notes in the official tariff — they include and exclude items explicitly.
  3. Pick the heading whose wording most specifically describes the product (General Interpretive Rule 1).
  4. For sets, mixtures and multi-function goods, apply the remaining General Interpretive Rules in order.
  5. Where real money is at stake, request a binding ruling from your customs authority.
Classification is your legal responsibility

Using a supplier's code without checking is a common and costly mistake. Misclassification can lead to back-duties, penalties and seized goods.

Frequently asked questions

Is an HS code the same as an HTS code or commodity code?

They share the same first six digits. HTS (US), CN/TARIC (EU) and UK commodity codes are national extensions of the international HS.

Which HS edition is in force?

The HS 2022 edition is currently applied by most countries. The WCO revises the nomenclature periodically, so check the edition your customs authority uses.

Can I use the export code from my supplier?

Use it as a hint only. Export and import codes can differ beyond six digits, and the importer is responsible for the declared import classification.
